Issuance of Skipper License

This manual serves as a comprehensive guide for users involved in the process of obtaining skipper licenses using the MSDFAR system.

    1.Introduction

The skipper licensing system is designed to streamline the leader licensing process. It facilitates submission of applications, document verification, approval process and issuance of permits. This manual provides step-by-step instructions for users to navigate the system effectively.

    2. System Access:

Note: Before registering as a skipper, must be registered as a fisherman with this Department.

•Before access to the system, scan & save the following documents.

     Duly filled application form
     Copy of skipper certificate
     Copy of fisherman ID
     Copy of National ID
     Payment Receipt

• Access to the MSDFAR system

The system can be accessed through Officer → New MSDFAR System by visiting the Department of Fisheries and Aquatic Resources website.

    • Users authorized to access the system will be provided with login credentials.

    • Upon successful login, users will have access to the dashboard with relevant features and functionalities.

    3. Application Process:

Afterward, entry to the Skipper license module in the manual bar of the screen that appears can be made.

• This screen can be seen once the skipper license in the manual bar is clicked on.

    1. Fisherman ID

    2. Highest education qualification

    3. Other qualifications

    4. Fisheries district

    5. Fisheries division

    6. Education qualifications

      a. Institute

      b. Program name

      c. Training period

      d. Date certified

    7. Trainings - By clicking on Add Training, the details of the training programs attended by the pilot can be entered

    • Fill out the application form with accurate details of the Skipper.
    • Upload the required documents, including the skipper certificate, fisherman ID, and National ID.
    • Verify the information entered before uploading the application.
    • It is then forwarded to the District Fisheries Inspector.

    4. Verification and Approval:

• District Fisheries Inspector will verify the applicant's information against the fisherman registration system.

• This screen can be seen once the skipper license in the manual bar is clicked on.

    • Upon verification, the application will be forwarded to the District Assistant Director for approval.
    • The District Assistant Director will review and approve the application in the system. The number of licenses to be approved, number of completed licenses, number of final approvals, and expired licenses can be viewed by the District Assistant Director.

    • The application will then be forwarded to the Director (Management) at the head office for further verification.
    • Finally, Director (Management) check and verify the application and forward to the DG.
    • The payment receipts can be uploaded in the system after obtaining the approval of the Director General.

    5. Printing of Skipper ID License:

• The officer in the Development division will print the skipper ID license send it to relevant district office.
